# 🛠️ AgentSkill

A curated collection of specialized AI skills designed to extend an AI agent's capabilities in handling specific tasks like document manipulation, code humanization, and UI/UX design.

Each folder in this repository represents a distinct skill that an AI Assistant can utilize to work more efficiently and accurately.

## 📂 Available Skills & Their Functions

Below is an overview of each available skill and its core functions:

### 1. 📄 docx-skill (Microsoft Word Manipulation)
**Folder:** `docx-skill/`

This skill is triggered whenever the AI needs to create, read, edit, or manipulate Microsoft Word documents (`.docx`).
- **Core Functions:** 
  - Generating professional documents (reports, memos, letters, templates).
  - Applying formatting such as Tables of Contents, headings, page numbers, and letterheads.
  - Extracting or reorganizing content from existing Word files.
  - Inserting or replacing images within documents.
  - Performing find-and-replace operations, and working with tracked changes or comments.

### 2. 💻 humanize-coding (Natural-Looking Code)
**Folder:** `humanize-coding/`

This skill ensures that code generated by the AI looks as if it were written by a real human developer, eliminating predictable AI coding patterns ("tells").
- **Core Functions:**
  - Removing over-commenting and unnecessary explanations.
  - Avoiding robotic and rigid variable naming conventions.
  - Breaking away from standard "textbook" code structures.
  - Highly useful when writing, refactoring, or reviewing code across all programming languages.

### 3. 📕 pdf-skill (Advanced PDF Processing)
**Folder:** `pdf-skill/`

This skill enables the AI to interact comprehensively with PDF files.
- **Core Functions:**
  - Reading and extracting text or tables from PDFs.
  - Merging multiple PDF files into one or splitting a single PDF into several files.
  - Rotating pages, adding watermarks, and creating new PDFs.
  - Filling out PDF forms and performing encryption/decryption.
  - Extracting images and applying OCR to scanned PDFs to make their text searchable.

### 4. 📊 pptx-skill (PowerPoint Presentation Manipulation)
**Folder:** `pptx-skill/`

This skill is utilized whenever a `.pptx` file is involved, either as an input or an output.
- **Core Functions:**
  - Creating slide decks, pitch decks, or presentations from scratch.
  - Reading, parsing, and extracting text from presentation slides (e.g., for summaries or emails).
  - Editing and updating existing presentations.
  - Merging or splitting slide files.
  - Working seamlessly with templates, layouts, speaker notes, and comments.

### 5. ✍️ stop-slop (AI Writing Pattern Remover)
**Folder:** `stop-slop/`

This skill acts as a prose editor to eliminate predictable and robotic AI writing patterns ("AI slop").
- **Core Functions:**
  - Removing cliché phrases, predictable sentence structures, and overly formal language.
  - Best used when drafting, editing, or reviewing text to ensure the final output feels human, crisp, and authentic.

### 6. 🎨 ui-ux-promax (UI/UX Design Intelligence)
**Folder:** `ui-ux-promax/`

This skill serves as an advanced design assistant for web and mobile development, bringing professional UI/UX principles directly into the codebase.
- **Core Functions:**
  - Providing guidelines for 50+ visual styles (glassmorphism, minimalism, bento grid, dark mode, etc.).
  - Assisting with color palette selection (161 palettes), font pairings (57 pairings), and UX principles (99 guidelines).
  - Integrating smoothly with modern tech stacks like React, Next.js, Tailwind, Vue, Svelte, Flutter, and component libraries like *shadcn/ui*.
  - Reviewing, optimizing, and fixing UI code to ensure pixel-perfect, highly aesthetic, and accessible results.

### 7. 📈 xlsx-skill (Spreadsheet & Tabular Data Manipulation)
**Folder:** `xlsx-skill/`

A specialized skill for handling tabular data and spreadsheet files such as `.xlsx`, `.xlsm`, `.csv`, or `.tsv`.
- **Core Functions:**
  - Opening, reading, editing, or fixing existing spreadsheet files.
  - Computing formulas, formatting cells, generating charts, and cleaning messy data.
  - Creating new spreadsheets from external data sources or converting between tabular formats.
  - Restructuring malformed rows, misplaced headers, or junk data into a clean, organized table format.

## 🚀 How to Use

This collection of skills is designed for use by AI agents that support "Skill/Tool" integration systems. The AI will automatically trigger the appropriate skill when the user's prompt matches relevant keywords (e.g., *"create a Word document"*, *"fix this Tailwind styling"*, or *"merge these two PDFs"*).

Each folder contains a `SKILL.md` file (and necessary helper scripts) with comprehensive instructions and documentation for handling specific tasks.
