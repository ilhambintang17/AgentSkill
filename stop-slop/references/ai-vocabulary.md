# AI vocabulary and style tells

## Overused AI words

These words appear far more frequently in post-2023 text. They often co-occur. Replace with simpler alternatives or cut entirely.

| AI word | Alternatives |
|---------|-------------|
| Actually | (cut) |
| Additionally | Also, or just start the sentence |
| Align with | Match, fit |
| Crucial | Important, or name why |
| Delve | Look at, examine |
| Emphasizing | (cut the -ing clause) |
| Enduring | Lasting, or cut |
| Enhance | Improve |
| Fostering | Building, creating |
| Garner | Get, earn |
| Highlight (verb) | Show, point out |
| Interplay | Interaction, relationship |
| Intricate / intricacies | Complex, or name the specific complexity |
| Key (adjective) | Important, main, or cut |
| Landscape (abstract) | Field, situation, area |
| Pivotal | Important, or cut |
| Showcase | Show, demonstrate |
| Tapestry (abstract) | (cut the metaphor, state the thing) |
| Testament | Evidence, proof, or just state the fact |
| Underscore (verb) | Show, make clear |
| Valuable | Useful, or name the specific value |
| Vibrant | (cut, or name the specific quality) |

## Promotional and ad-like words

LLMs can't keep a neutral tone, especially for cultural or heritage topics.

| Word | Problem |
|------|---------|
| Boasts a | Promotional. Use "has" |
| Vibrant | Vague positive |
| Rich (figurative) | Empty modifier |
| Profound | Inflated |
| Enhancing its | Promotional padding |
| Showcasing | Ad copy |
| Exemplifies | Puffery |
| Commitment to | Corporate speak |
| Natural beauty | Stock phrase |
| Nestled | Travel brochure |
| In the heart of | Same |
| Groundbreaking (figurative) | Almost always inflated |
| Renowned | Unsupported claim |
| Breathtaking | Travel brochure |
| Must-visit | Same |
| Stunning | Empty superlative |

## Significance and legacy words

LLMs inflate importance with these. Cut or replace with specific facts.

| Word/phrase | Problem |
|-------------|---------|
| Stands/serves as | Copula avoidance. Use "is" |
| Is a testament/reminder | Inflated framing |
| A vital/significant/crucial/pivotal/key role/moment | Puffery stack |
| Underscores/highlights its importance/significance | Padding |
| Reflects broader | Vague trend connection |
| Symbolizing its ongoing/enduring/lasting | Promotional |
| Contributing to the | Dodges specifics |
| Setting the stage for | Narrative template |
| Marking/shaping the | Inflated claim |
| Represents/marks a shift | Unsupported |
| Key turning point | Double modifier |
| Evolving landscape | Empty metaphor |
| Focal point | Vague |
| Indelible mark | Puffery |
| Deeply rooted | Same |

## Vague attribution words

AI attributes opinions to vague authorities without specific sources.

| Phrase | Problem |
|--------|---------|
| Industry reports | Which ones? |
| Observers have cited | Who? |
| Experts argue | Name them |
| Some critics argue | Name the critics |
| Several sources/publications | Cite them |

**Instead:** "According to a 2019 survey by [specific organization]."

## Style tells

### Em dashes and en dashes

The em dash is one of the most reliable AI tells. The final text should contain no em dashes (—) or en dashes (–). Also catch spaced em dashes (` — `) and double hyphens (` -- `).

Replace with (in order of preference):
1. A period (start a new sentence)
2. A comma (tight aside)
3. A colon (introducing an explanation)
4. Parentheses (true aside)
5. Restructure the sentence

### Overuse of boldface

AI emphasizes phrases in boldface mechanically. Remove bold from ordinary terms. Bold should be rare and intentional.

### Inline-header vertical lists

Items starting with bolded headers followed by colons. Convert to prose.

**Before:**
> - **User Experience:** The interface has been improved.
> - **Performance:** Algorithms have been optimized.

**After:**
> The update improves the interface and speeds up load times through optimized algorithms.

### Title case in headings

AI capitalizes all main words. Use sentence case.

**Before:** ## Strategic Negotiations And Global Partnerships
**After:** ## Strategic negotiations and global partnerships

### Emojis

AI decorates headings or bullets with emojis. Remove them.

### Curly quotation marks

ChatGPT uses curly quotes ("...") instead of straight quotes ("..."). Straighten them.

### Hyphenated word pair overuse

AI hyphenates compounds uniformly, including in predicate position. Keep attributive hyphens ("a high-quality report"). Drop them when the compound follows the noun ("the report is high quality").

Common over-hyphenated pairs: third-party, cross-functional, client-facing, data-driven, decision-making, well-known, high-quality, real-time, long-term, end-to-end.
