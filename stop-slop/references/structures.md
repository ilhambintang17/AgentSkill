# Structures to avoid

## Binary contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |

**Instead:** State Y directly. "The problem is Y." Drop the negation entirely.

## Negative parallelisms and tailing negations

Constructions like "Not only...but..." or "It's not just about..., it's..." are overused. Also catch tailing-negation fragments ("no guessing," "no wasted motion") tacked onto sentences instead of real clauses.

| Pattern | Problem |
|---------|---------|
| "It's not just about X, it's Y" | Formulaic double-beat |
| "Not only X but also Y" | Same structure |
| "...no guessing" (tailing fragment) | Clipped negation instead of a sentence |
| "...no wasted motion" | Same |

**Instead:** State Y directly. For tailing negations, write a real clause: "without forcing the user to guess."

## Negative listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader doesn't need the runway.

## Dramatic fragmentation and manufactured punchlines

Sentence fragments for emphasis read as manufactured profundity. LLMs also stack short declarative fragments to manufacture drama. A single short sentence for emphasis is fine; a run of them is engineered.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |
| "Then X arrived. It had no preference. No aesthetic prior. The old rules were gone." | Stacked fragments inflating tone |

**Instead:** Complete sentences. Trust content over presentation. Combine fragments into real sentences.

## Rhetorical setups

These announce insight rather than deliver it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |

**Instead:** Make the point. Let readers draw conclusions.

## Formulaic constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## Outline-like "Challenges and future prospects"

Many AI articles include formulaic challenge sections.

| Pattern | Problem |
|---------|---------|
| "Despite its... faces several challenges..." | Formulaic difficulty framing |
| "Despite these challenges, [optimistic pivot]" | Predictable recovery |
| "Challenges and Legacy" / "Future Outlook" | Section heading tells |

**Instead:** Name the specific challenge and what was done about it. "Traffic congestion increased after 2015. The corporation began a drainage project in 2022."

## Aphorism formulas

LLMs turn ordinary claims into reusable aphorisms that sound profound without adding precision.

| Pattern | Problem |
|---------|---------|
| "X is the Y of Z" | Manufactured depth |
| "X becomes a trap" | False drama |
| "X is not a tool but a mirror" | Pseudo-philosophy |
| "the language of" / "the currency of" / "the architecture of" | Metaphor template |

**Instead:** State the concrete claim the aphorism gestures at.

## False agency

Giving inanimate things human verbs. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Someone kills the project or ships it. |
| "the decision emerges" | Someone decides. |
| "the culture shifts" | People change behavior. |
| "the conversation moves toward" | Someone steers. |
| "the data tells us" | Someone reads it and draws a conclusion. |
| "the market rewards" | Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week."

## Narrator-from-a-distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats "Nobody designed this."

## Passive voice and subjectless fragments

Every sentence needs a subject doing something. Passive voice hides the actor. Subjectless fragments like "No configuration file needed" are equally evasive.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |
| "No configuration file needed." | "You do not need a configuration file." |
| "The results are preserved automatically." | "The system preserves the results." |

**Instead:** Find the actor. Put them at the front of the sentence.

## Copula avoidance

LLMs substitute elaborate constructions for simple "is" or "has."

| Pattern | Fix |
|---------|-----|
| "serves as" | "is" |
| "stands as" | "is" |
| "marks" | "is" |
| "represents" | "is" |
| "boasts" | "has" |
| "features" | "has" |
| "offers" | "has" or "provides" |

## Superficial -ing analyses

AI tacks present participle phrases onto sentences to add fake depth.

| Pattern | Problem |
|---------|---------|
| "highlighting/underscoring/emphasizing..." | Padding |
| "ensuring..." | Vague promise |
| "reflecting/symbolizing..." | Inflated meaning |
| "contributing to..." | Dodges specifics |
| "cultivating/fostering..." | Promotional |
| "encompassing..." | Overreach |
| "showcasing..." | Ad copy |

**Instead:** End the sentence. Start a new one with the specific claim.

## Sentence starters to avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or verb. |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes the specific constraint.

## Significance inflation

LLMs puff up importance by adding statements about how arbitrary aspects represent broader topics.

| Pattern | Problem |
|---------|---------|
| "marking a pivotal moment in" | Inflated importance |
| "a testament to" | Same |
| "underscores its importance" | Same |
| "reflects broader" | Vague connection to trend |
| "symbolizing its ongoing" | Promotional |
| "setting the stage for" | Narrative template |
| "represents a shift" | Unsupported claim |
| "indelible mark" | Puffery |

**Instead:** State what actually happened and why it mattered to specific people.

## Fragmented headers

A heading followed by a one-line paragraph restating the heading before the real content begins.

**Before:**
> ## Performance
>
> Speed matters.
>
> When users hit a slow page, they leave.

**After:**
> ## Performance
>
> When users hit a slow page, they leave.

## Diff-anchored writing

Documentation written as if narrating a change rather than describing the thing as it is. Unless the document is version-scoped (changelogs, release notes), it should read coherently without knowing what changed.

**Before:**
> This function was added to replace the previous approach of iterating through all items.

**After:**
> This function uses a hash map for O(1) lookups.

## Rhythm patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Use two items or one |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Em dashes | Remove. Use commas or periods. |
| Staccato fragmentation | Don't stack short punchy sentences |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Elegant variation (synonym cycling)

AI has repetition-penalty code causing excessive synonym substitution.

**Before:**
> The protagonist faces challenges. The main character must overcome obstacles. The central figure triumphs. The hero returns home.

**After:**
> The protagonist faces many challenges but eventually triumphs and returns home.

## False ranges

LLMs use "from X to Y" constructions where X and Y aren't on a meaningful scale.

**Before:**
> From the singularity of the Big Bang to the grand cosmic web, from birth and death of stars to the dance of dark matter.

**After:**
> The book covers the Big Bang, star formation, and current theories about dark matter.

## Word patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics. |
| All adverbs (-ly words, "really," "just," "literally") | Empty emphasis. See phrases.md. |
